🚀 Hotspots Near Me – Backend
📌 Overview

This project is the backend for the Hotspots Near Me platform, which helps identify the best locations to start a business using geographic and spatial data analysis.

⚙️ Features
Fetches location data using Overpass API
Analyzes competition density
Applies business-specific rules
Provides ranked hotspot recommendations

🛠️ Tech Stack
Python
Overpass API (OpenStreetMap)
Redis (for caching)
Supabase
